# Ограничения — честный список

## Ядро

- **Такты однопоточны.** Регионы шагают последовательно по возрастанию id — это часть
  детерминизма. Параллелизм возможен только как опциональный feature-флаг с детерминированной
  сборкой результатов; в ядре его нет.
- **`f32` и строгий порядок операций.** Бит-точный реплей означает: никаких fast-math
  сокращений, переассоциаций и FMA-подстановок компилятором сверх зафиксированного порядка.
  Точность физики — в пределах `f32`.
- **`EventType` — фиксированные 8 типов.** Расширение — через собственные обработчики поверх
  `EventQueue`, но перечисление типов фиксировано (это цена типобезопасности без зависимостей).
- **Диффузия — ядро 3×3** (фон Неймана / Мура) на процесс-правило. Большие ядра или
  переменные радиусы в ядро не входят.

## Визуализация и данные

- **PNG-экспорт — stored-deflate (без сжатия).** Писатель без зависимостей, зато большие
  хитмапы весят как несжатый RGBA. CSV-экспорт — построчный текст, тоже без сжатия.
- Персистентность состояния — только снапшоты в памяти и CSV/PNG наружу. Формата сохранения
  мира на диск в ядре нет (осознанно: это слой, а не ядро).

## Перенос с C++

- API-уровень отличается: `Result` вместо исключений, `Option` вместо `at()`-исключений,
  без дефолтных аргументов. Код на C++ API переносится механически, но не компилируется как есть.
- `RegionWork` получил явный параметр `&mut RegionScheduler` — реентрантность теперь видно
  в сигнатуре.
- Семантика поведения сохранена и закреплена тестами (включая референсные векторы SplitMix64
  и бит-точный откат); «примерно так же, как в C++» — не считается.
