# Changelog — EAFAR

Все заметные изменения фиксируются здесь. Формат — упрощённый [Keep a Changelog](https://keepachangelog.com/).

## Unreleased — апгрейд по аудиту (2026-11)

### Добавлено

- `docs/model.md` — формализация модели: разреженный CA с активным множеством `A_t`,
  жизненный цикл сна/пробуждения, модель стоимости и потенциальный выигрыш `≈ 1/α`
  от активной доли, компромисс локальности/размера кадра, детерминизм и хэш состояния;
  честный раздел о нечётком слое: реализованы ТОЛЬКО функции принадлежности
  (step/ramp/triangle/bell) и именованный реестр — t-нормы, t-конормы, импликация,
  вывод правил и дефаззификация отсутствуют (никаких заявлений о производительности
  нечёткого вывода).
- `docs/benchmarks.md` — реальные числа из запуска `eafar-bench`: dense synchronous
  против sparse event-driven на трёх нагрузках (Conway Life, тепловая диффузия,
  пороговое заражение SIR) с метриками: доля активных ячеек, события (пересчёты
  ячеек), события/с, оверхед планировщика, память на активную ячейку, время стены
  на 300 ходов, проверка детерминизма (идентичные хэши между запусками) и
  cross-check «sparse == dense». Контекст машины: общая Linux-песочница, 2 vCPU —
  относительные значения значимы, абсолютные — нет.
- `src/workload.rs` — референсные CA-нагрузки (Conway / тепло / пороговое заражение)
  с общим per-cell ядром, `SparseSession` (event-driven драйвер поверх
  `RegionScheduler`: wake-on-change, wake-соседей по границе, idle-сон) и
  `DenseSession` (синхронный референс), `SessionCheckpoint` (честная перемотка:
  мир + активное множество + счётчики), FNV-1a-хэш состояния по битам `f32`.
- Свойство-тесты детерминизма/реплея `tests/suite/determinism.rs` (9 тестов):
  тот же сид → идентичный хэш между запусками; sparse воспроизводит dense
  бит-в-бит; откат чекпоинта + реплей бит-точны; воспроизводимость внедрения
  событий; расхождение разных сидов; контракт сна/пробуждения регионов.
- Крейт `viz` (workspace): интерактивный визуализатор на eframe/egui 0.29
  (glow/x11/default_fonts, без wgpu) — сетка CA, обводка активных регионов,
  play/pause/step/rewind по кольцевому буферу недавних состояний, выбор нагрузки,
  сид, живая статистика (поколение, активная доля, изменённые ячейки, события/с,
  хэш), клик по миру внедряет событие. GUI-логика (буфер отката, статистика EMA,
  playback-контроллер, захват/восстановление кадров) отделена от отрисовки и
  покрыта юнит-тестами, которые проходят без egui (5 тестов, `cargo test -p viz`).
- Фича `gui` у `viz` — опциональна: сборка GUI требует **cargo ≥ 1.85** (часть
  дерева egui/eframe несёт манифесты edition 2024; на cargo 1.83
  `cargo check -p viz --features gui` падает с `feature 'edition2024' is required`).
  Корневой `Cargo.lock` коммитится и пинит всё дерево `viz` (318 пакетов).
- CI-джоба `viz-check`: `cargo check -p viz` (логика) и `cargo check -p viz
  --features gui` на стабильном тулчейне с apt-пакетами libxkbcommon-dev,
  libxkbcommon-x11-dev, libwayland-dev; `continue-on-error: true` — не блокирует merge.
- Бенчмарк `eafar-bench` расширен (часть 1): таблица dense-vs-sparse в формате
  markdown + детальные строки; легаси-микробенч планировщика сохранён (часть 2).

## v1.0.0 — переписывание на Rust (2026-10-30)

`main` теперь чистый Rust-крейт; реализация на C++23 живёт в истории git.

### Добавлено

- крейт `eafar` 1.0.0 (edition 2021): ноль зависимостей, `#![forbid(unsafe_code)]`;
- модули S1–S10: `field_map`, `event_queue`, `region_scheduler`, `automaton`, `fuzzy`,
  `dependency`, `diffusion`, `snapshot`, `rng`, `visualizer` + `prelude`;
- 78 контрактных тестов (C++-набор — 72+) перенесён и расширен, включая:
  референсные векторы SplitMix64 (бит-в-бит), бит-точный откат снапшотов
  (паттерны NaN, `-0.0`), реплей-идентичность после отката;
- бенчмарк перенесён в `src/bin/eafar-bench.rs` (std::time::Instant, без criterion);
- пример `examples/heatmap.rs` — картинка разреженного мира с обводкой активных регионов;
- CI на cargo (build + test, неблокирующий cross-check на Windows/macOS).

### Изменено (семантика сохранена, уровень API)

- исключения → `Result<T, Error>`; тексты ошибок сохранены;
- `EventType::_count` и пустые membership-состояния убраны (в Rust непредставимы);
- `AutomatonManager::at` возвращает `Option` вместо исключения;
- `RegionWork` принимает явный `&mut RegionScheduler` (в C++ замыкание захватило по ссылке);
- дефолтный аргумент `payload = 1.0f` убран — все вызовы передают его явно;
- CSV-писатель воспроизводит формат `%g` (6 значащих цифр) `ostream<<`.

### Гарантии детерминизма (перенесены и протестированы)

SplitMix64 бит-в-бит с C++; снапшоты бит-точные; обход — по возрастанию id (`BTreeSet`);
порядок float-операций в диффузии совпадает с C++ (тот же порядок соседей ядра).

## v0.1.0 — first snapshot (2026-10-16)

- библиотека C++23: S1–S10 (FieldMap, EventQueue, RegionScheduler, AutomatonManager,
  FuzzyState, DependencyGraph, DiffusionEngine, WorldSnapshot, RNG, Visualizer);
- 72+ контрактных теста, бенчмарк разреженности (~сотни× на 0.1% активных регионов);
