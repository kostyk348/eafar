# Логотип EAFAR — текстовая концепция

## Идея

**Мир, который спит, и точка внимания, которая будит.** Тёмная сетка 8×8 ячеек
(половина ячеек — приглушённые «спящие»), три соседних ячейки в правом верхнем
квадранте горят через ramp-палитру хитмапы (синий → зелёный → жёлтый → красный)
и обведены тонкой рамкой «активного региона». Вокруг горящих ячеек — лёгкий
ореол: это диффузия, главный визуальный мотив движка.

## Геометрия

- Сетка построения — 32×32, знак вписан в квадрат со скруглением 15%;
- сетка ячеек: 8×8 с зазором в 1 единицу, «спящие» ячейки залиты фоном чуть
  светлее подложки (как будто видны в темноте);
- активный регион — блок 2×2 ячейки, рамка 1.5 единицы, скруглённые углы;
- ореол — размытие 2 единицы вокруг активного блока;
- в favicon (16 px) сетка упрощается до 4×4, остаётся один горящий регион.

## Палитра

| роль | цвет | где |
| --- | --- | --- |
| фон | `#0D1117` | подложка знака |
| спящие ячейки | `#161B22` | сетка простоя |
| ramp-активность | `#1F6FEB → #2EA043 → #D29922 → #F85149` | горящие ячейки (по возрастанию значения поля) |
| рамка региона | `#3FB950` | обводка активного блока |

Ramp взят из экспорта `Visualizer::export_heatmap_png` — логотип буквально
нарисован палитрой движка.

## Типографика

Слово-логотип — eafar строчными, геометрический гротеск (Inter / Noto Sans),
вес 600, трекинг −1%. Капслоком пишется только развёрнутое имя в шапке
документов: EAFAR. Моноширинные начертания — только для кода, не для знака.

## Что запрещено

- Не подсвечивать больше одного региона-блока (теряется сюжет «разреженности»);
- не делать все ячейки одинаково тусклыми (знак перестаёт читаться на 16 px);
- не добавлять градиенты вне ramp-палитры и любые тени, кроме ореола диффузии.
